## 二、开篇原文（**金句·可直接引用**）

> 「由四川过湖南去，靠东有一条官路。这官路将近湘西边境到了一个地方名为『茶峒』的小山城时，有一小溪，溪边有座白色小塔，塔下住了一户单独的人家。**这人家只一个老人，一个女孩子，一只黄狗。**」

- 这一句是全书最有名的开场，**「一个老人，一个女孩子，一只黄狗」**是全书最小的单位，也是全书的全部。

## 三、人物（确定信息）

| 人物 | 身份与要点 |
|---|---|
| **翠翠** | 老船夫的外孙女，十四五岁（书中称「小兽物」般天真）。父母双双殉情后由外祖父在溪边养大。皮肤黑黑的，眸子清明如水晶，「为人天真活泼，处处俨然如一只小兽物」「从不想到残忍事情，从不发愁，从不动气」 |
| **老船夫（祖父）** | 在碧溪岨这条小溪上**摆渡了五十年**。渡船是公家的，**过渡人给钱他不肯收**，实在推不掉就拿去买茶叶和草烟，泡一大缸茶水放在船头，谁过路谁喝。心里最放不下的一件事：**翠翠的婚事** |
| **黄狗** | 陪翠翠的一只黄狗，跟着她上城、下河、听歌 |
| **翠翠的母亲** | 老船夫的独生女儿。十七年前与当地一个军人相爱，想私奔又各有顾虑，走不成，**先后殉情**（军人先服毒，母亲生下翠翠后也随他而去）。这一段是全书没有正面写、却一直压在老船夫心里的痛 |
| **天保（大老）** | 掌水码头的船总**顺顺**的大儿子，身强力壮，性情爽直，**也爱翠翠**，走的是**「车路」**：托人向老船夫正经说媒 |
| **傩送（二老）** | 顺顺的二儿子，**会唱歌**，人称「岳云」。走的是**「马路」**：夜里到碧溪岨对溪的高崖上，为翠翠唱歌。他**不要碾坊，宁要渡船** |
| **顺顺** | 掌水码头的船总，辛亥革命后回乡，为人豪爽仗义，两个儿子的父亲 |
| **杨马兵** | 老船夫的老友，早年曾托人向翠翠的母亲提过亲。老船夫死后，是他来陪着翠翠 |

## 四、故事情节（按顺序·写稿主干）

> 写稿时**以此节为情节骨架**，每一段都可以展开成一个「场面」。

1. **摆渡的日子**。小溪边一座白塔，塔下一户人家：老人、女孩、黄狗。渡船来去，过渡的多是乡下人，挑着担子、赶着羊、带着新娘子回门的。老船夫不收钱，船上总有他泡好的一缸茶。翠翠一天天长大，长了十五岁，心里开始有些说不清的、自己也说不出口的东西。

2. **端午·第一次见傩送**。城里年年端午赛龙船。翠翠跟祖父进城看热闹，祖父被人拉去喝酒、走不开，天黑了翠翠一个人在河边等。是**傩送（二老）**派人送她回碧溪岨去——翠翠误以为他不安好心，还放狗咬了他。第二天才知道，那个「轻薄」她的人，就是顺顺家会唱歌的二老。同年端午，傩送在河里**捉鸭子**（当地端午的风俗，泗水捉水上的鸭子），一把就抓到了最肥的那只。（（资料待补）具体年份顺序如需精确，先向 007 确认；本书两度写端午，写稿以「端午看龙船 → 河边相逢」为准。）

3. **兄弟两个都爱上了翠翠**。天保先向老船夫提亲，走的是车路。老船夫回来问翠翠的意思，翠翠不答，低头、躲开，只把手里的东西揉来揉去。

4. **兄弟摊牌 · 车路与马路**。兄弟两人把话说开：都爱翠翠。按当地风俗，**车路是请人说媒，马路是站在对溪高崖上唱歌，唱到对方心动**。天保唱歌唱不过弟弟，说了一句大意是「我唱不过你，我走车路」；傩送则说，他要在碧溪岨唱**三年六个月**的歌。

5. **梦里的虎耳草**。那个晚上，翠翠听着对溪传来的歌声睡着了，**梦里飞到悬崖半腰去摘虎耳草**——她摘了一大把。第二天她跟祖父说这个梦，祖父笑她。**虎耳草**是全书最要紧的一个意象：那是她心里那件「不知道是什么」的事，第一次有了形状。（（资料待补）虎耳草一段的更细对白如需引用，先核通行本原文。）

6. **天保之死**。天保知道弟弟也爱翠翠之后，心里有了结，**坐上船下行做生意，途中遇难，溺水而死**。（（资料待补）具体滩名与经过，如需写出先核通行本，不要凭印象写「滩名」。）消息传回茶峒，一条溪、两家人，从此都不一样了。

7. **碾坊与渡船**。傩送是茶峒最好的人家的二儿子，有人家愿意**用一座碾坊作陪嫁**把女儿许给他——碾坊是能生钱的产业，而翠翠只有一条渡船。傩送的选择是：**不要碾坊，要渡船**。这句话是全书最硬的一个立场，也是全书最动人的地方之一。

8. **傩送出走**。哥哥的死，让傩送一家对老船夫生出了说不清的隔阂；傩送本人也把哥哥的死记在自己心里。他**离开茶峒，下行去桃源方向做生意**（（资料待补）与「下桃园/下桃源」记载略有出入，写稿只说「下行远走」即可，不要写死地名）。

9. **老船夫之死**。一个**雷雨夜**，老船夫在溪边去世。同一个夜里，**溪边那座白塔塌了**。（后来塔又重新修起来。）顺顺来了，杨马兵来了，把他安葬。翠翠成了独自守着渡船的那个人——杨马兵要来接替她，她不肯，她自己摆渡。

10. **结尾**。老船夫死了，渡船还在。翠翠留在碧溪岨，一边摆渡，一边等一个人回来。

## 五、结尾原文（**金句·全书最后一句，必用**）

> 「**这个人也许永远不回来了，也许『明天』回来！**」

- 这是全书的最后一句，也是中国现代文学里最有名的结尾之一。
- 建议：**放在讲书稿最末**，不要在前面提前用掉。

## 七、意象清单（写稿时反复回扣的东西）

| 意象 | 在书里的意义 |
|---|---|
| **渡船 / 摆渡** | 老船夫一辈子的活计；翠翠的人生；「把别人送过去，自己留在原地」 |
| **白塔** | 溪边的地标；老船夫死的那夜塌了，后来又修起来 |
| **黄狗** | 翠翠的伴；一人一狗的安静 |
| **溪水 / 大河** | 绿水、清亮、缓慢；也是夺走天保的东西 |
| **虎耳草** | 少女心里那件说不出口的事，第一次有了形状 |
| **唱歌（马路）** | 傩送求爱的方式；夜里对溪高崖上的歌声 |
| **碾坊 vs 渡船** | 富贵的陪嫁 vs 一条公家渡船；傩送的选择 |
| **船 / 下水远行** | 天保的死、傩送的出走，都从「上船」开始 |
| **端午 / 中秋 / 过年** | 边地小城一年里的热闹节点，翠翠的心事都在这几个节点上发生 |

## 八、写稿提示

1. **一个核心**：这本书讲的是「**一个在溪边长大的女孩，和那条溪上的人间**」——她的心事没人教过她怎么说，于是日子一天天过去，人等的人没有回来。落点放在「**等待**」与「**没有被说出口的爱**」，不要讲成「封建礼教害死人」的说教。
2. **讲场面，不讲评价**：写「过渡人递钱、老船夫笑着推开」「雷雨夜塔塌了」这样的具体场面，不要写「作者以诗意的笔触」这类书评话。
3. **旁白要有水汽**：这是一本水边的书。画面尽量落在**水、船、塔、竹、雾、雨、月、灯**上。
4. **结尾收在那句话上**：把「这个人也许永远不回来了，也许『明天』回来！」留给最后。
5. **民俗细节要准确**：端午赛龙船与捉鸭子、走车路（说媒）与走马路（唱歌）、过渡不收钱——这些是本书的质地，写准它们比抒情重要。
