## 一、年龄段处理逻辑

### 1.1 婴幼儿 (toddler, 0-3岁)

**核心策略**：不讲道理，只讲故事。零概念、纯感官。

- **脚本结构**：不做"观点+论据"，改为"场景→事件→感受"三段式
- **语言规则**：
  - 每句≤8个字
  - 大量叠词、拟声词（"咕噜咕噜""哗啦啦"）
  - 重复句式（"小熊走啊走，走啊走..."）
- **声音**：小双(Xiaoshuang)，语速-20%，段间停顿800ms
- **BGM**：轻音乐盒/钢琴，音量-30dB
- **内容过滤**：strict模式，禁止任何暴力/死亡/恐怖/分离焦虑
- **家长指引**：每段结束后加"爸爸妈妈可以..."提示

**示例风格**：
> 小鸟叫，叽叽叽。小猫走，喵喵喵。宝宝听，宝宝笑。今天的故事，关于一只小兔子。

### 1.2 学龄前 (preschool, 3-6岁)

**核心策略**：故事为主，道理藏在故事里，不直说。

- **脚本结构**：
  1. 开场问候（15秒）→ "小朋友们，今天我们要认识一位新朋友"
  2. 故事主体（4-6分钟）→ 简单情节+丰富细节
  3. 互动提问（1分钟）→ "你觉得小兔子会怎么做呢？"
  4. 总结（30秒）→ 一句话点出道理
  5. 结尾（15秒）→ 温柔收尾
- **语言规则**：
  - 每句≤12个字
  - 用"你"称呼，像跟小朋友面对面
  - 每讲一段停下来提问
- **声音**：晓晓(Xiaoxiao)，语速-15%，温暖亲切
- **内容过滤**：strict模式，禁止暴力/惊吓/死亡/离婚
- **推荐类别**：童话故事、动物故事、科学启蒙、成长励志

### 1.3 小学低年级 (primary_lower, 6-9岁)

**核心策略**：故事+知识点，开始有"学到了什么"。

- **脚本结构**：
  1. 悬念开场 → 引出一个问题
  2. 故事展开 → 情节+角色+冲突
  3. 知识发现 → "原来这就是..."
  4. 生活联系 → "你也可以试试..."
- **语言规则**：
  - 每句≤20个字
  - 可以有一些成语但必须解释
  - 适当加入"你知道吗？"的科普元素
- **声音**：晓晓(Xiaoxiao)，语速-10%
- **内容过滤**：moderate模式，禁止暴力/悬疑，但可以有轻度冒险
- **深度支持**：quick/standard/deep

### 1.4 小学高年级 (primary_upper, 9-12岁)

**核心策略**：多观点+案例，开始培养独立思考。

- **脚本结构**：
  1. 问题引入 → "你有没有想过..."
  2. 观点1+案例 → 具体故事
  3. 观点2+对比 → 不同角度看
  4. 思考题 → "如果是你，你会怎么做？"
  5. 总结 → 核心收获
- **语言规则**：
  - 每句≤30个字
  - 可以用比喻、类比
  - 适当引入历史/科学背景
- **声音**：云希(Yunxi)，语速-5%，阳光积极
- **内容过滤**：moderate模式
- **深度支持**：quick/standard/deep

### 1.5 初中 (middle_school, 12-15岁)

**核心策略**：批判性思考，不只给答案，给思考工具。

- **脚本结构**：
  1. 矛盾引入 → 两种观点的冲突
  2. 深入分析 → 论据+数据+历史案例
  3. 批判思考 → "但也有人认为..."
  4. 延伸思考 → 联系当下/未来
  5. 开放结尾 → 不给标准答案
- **语言规则**：
  - 正常语速，不过度简化
  - 可以用专业术语但需解释
  - 引入跨学科视角
- **声音**：云健(Yunjian)，沉稳理性
- **内容过滤**：light模式，只过滤极端内容
- **深度支持**：quick/standard/deep/full

### 1.6 高中 (high_school, 15-18岁)

**核心策略**：深度分析，接近成人水平但保持可读性。

- **脚本结构**：接近成人standard模式，但案例更贴近青少年
- **语言规则**：正常成人语言，不过度简化
- **声音**：云扬(Yunyang)，浑厚有深度
- **内容过滤**：light模式
- **深度支持**：quick/standard/deep/full

### 1.7 成人 (adult, 18+)

**核心策略**：完整精读，按所选depth生成对应深度。

- **脚本结构**：标准精读（见 prompts/standard_mode.txt）
- **语言规则**：正常成人表达，无限制
- **声音**：晓晓(Xiaoxiao)，语速可调
- **内容过滤**：off（仅拦截违法内容）
- **深度支持**：quick/standard/deep/full

## 二、场景适配细节

### 2.1 通勤 (commute)
- 信息密度高，不要废话
- 开场直接进入主题（不做长铺垫）
- 段间停顿短（300ms）
- 每段内容独立可理解（可能被打断）

### 2.2 跑步 (running)
- 节奏感强，金句密集
- 每段短小精悍（不超过2分钟）
- 语速+10%（配合运动节奏）
- 可加动感BGM
- 总时长≤8分钟（单次跑步可消化）

### 2.3 睡前 (bedtime)
- 语速-15%，语气温柔
- 不做悬念（避免兴奋）
- 结尾有总结安抚（"今天的内容就到这里..."）
- 段间停顿长（600ms）
- 轻音乐BGM
- 内容偏治愈/哲学/散文

### 2.4 亲子 (parent_child)
- 互动性强（有提问有回答）
- 适合家长和孩子一起讨论
- 语速适中偏慢
- 不做恐怖/暴力内容
- 时长≤10分钟（孩子注意力有限）

### 2.5 深度学习 (deep_learning)
- 逐章精讲，最详细
- 有论据有案例有批判性思考
- 语速正常
- 不加BGM（专注）
- 可长达30分钟

### 2.6 午休 (lunch_break)
- 轻量精华
- 一个核心观点+一个案例
- 语速正常
- 时长≤8分钟

## 三、深度等级对照

| 深度 | 时长 | 字数 | 结构 | 适用场景 |
|------|------|------|------|---------|
| quick | 3-5min | 300-500 | 结论+1个案例 | 午休/跑步 |
| standard | 7-10min | 700-1000 | 开场+3-4观点+金句+总结 | 通勤/通用 |
| deep | 12-20min | 1200-2000 | 观点+论据链+对比+批判+行动 | 睡前/深度学习 |
| full | 20-30min | 2000-3000 | 逐章精讲+多视角+扩展 | 深度学习 |

## 四、内容安全详细规则

### 4.1 Kids 模式（0-18岁所有年龄段）

**拦截类别**：
- 暴力/悬疑：杀人、谋杀、屠杀、凶杀、暴力、殴打...
- 死亡：死亡、自杀、去世、尸体...
- 恐怖：鬼、幽灵、恶魔、地狱、恐怖、诅咒...
- 成人：色情、性爱、裸体、强奸...
- 毒品：毒品、吸毒、海洛因...
- 犯罪：犯罪、抢劫、绑架、诈骗...
- 敏感政治：颠覆、政变、暴动...

**亲子额外提醒**：检测到恋爱/婚姻等话题时，不拦截，但提示家长"建议陪听"。

### 4.2 Adult 模式（18+）

**仅拦截**：贩毒、制毒、买卖枪支、制造炸弹、恐怖袭击、刺杀等违法内容。

### 4.3 自动映射
- age_group ∈ {toddler, preschool, primary_lower, primary_upper, middle_school, high_school} → kids 模式
- age_group = adult → adult 模式

## 五、书籍获取降级链

### 5.1 现代版权书（用 book_info.py）

- 书名在内置清单中（60+本经典）

## 六、声音克隆使用流程

### 6.1 录制要求
- 安静环境，无背景音乐
- 清晰人声，语速正常
- 20-30秒长度
- 内容建议："你好，我是爸爸/妈妈，今天给你讲一个小故事..."

### 6.2 配置
voice_clone:
  enabled: true
  engine: gpt_sovits      # 免费
  # 或 engine: elevenlabs  # 付费$5/月起

### 6.3 效果
- 所有给孩子的内容都用父母声音讲
- 默认"晓晓慢速讲故事"效果也很好

## 七、缓存机制

### 7.1 三级缓存

| 级别 | 缓存内容 | 缓存Key | TTL |
|------|---------|---------|-----|
| L1 | 精读脚本文本 | book_hash + age_group + scene + depth | 30天 |
| L2 | TTS音频片段 | text_md5 + voice + rate | 7天 |
| L3 | 成品MP3 | script_hash + voice + speed | 30天 |
### 7.2 缓存目录
~/.hermes/cache/listen-book/{l1,l2,l3}/

### 7.3 清理
from scripts.cache_manager import CacheManager
cm = CacheManager()
cm.clear()       # 清全部
cm.clear("l2")   # 清指定级别
cm.stats()       # 查看缓存占用

## 八、完整执行示例

### 场景A：成人通勤，现代书

用户："帮我解读《原子习惯》，通勤时听"

Step 1: 解析参数
  → book_title="原子习惯", age_group=adult, scene=commute, depth=standard

Step 2: 获取书籍信息
  → python scripts/book_info.py "原子习惯"
  → 返回：简介+豆瓣评分+金句+评价

Step 3: 生成精读脚本
  → 加载 prompts/standard_mode.txt
  → 将书籍信息填入模板
  → AI 生成结构化 JSON 脚本
  → content_filter 检查（adult模式，通过）

Step 4: TTS 转音频
  → 拼接所有 segment text 为完整文本
  → python scripts/streaming_pipeline.py -f script.txt --voice zh-CN-XiaoxiaoNeural --rate +5%
  → 自动分段→TTS→拼接→章节标记
  → 输出：~/listen-book/原子习惯_xxx.mp3

Step 5: 交付
  → 返回 MP3 文件 + Markdown 文稿
  → 末尾附购书链接

### 场景B：6岁儿童睡前

用户："给女儿解读《小王子》，她6岁，睡前听"

Step 1: 解析参数
  → book_title="小王子", age_group=primary_lower(6岁), scene=bedtime, depth=standard
  → 声音：晓晓, 语速：-10%, 场景降速：-15% → 综合约-25%

Step 2: 判断公版书
  → 《小王子》在公版书清单中（圣埃克苏佩里1944年逝世）
  → python scripts/book_fetcher.py "小王子"
  → 获取完整文本

Step 3: 生成精读脚本
  → 加载 prompts/children/primary_lower_mode.txt
  → AI 用适合6-9岁的语言生成故事式解读
  → content_filter 检查（kids模式）
  → 如有不适内容，替换并通知用户

Step 4: TTS 转音频
  → python scripts/streaming_pipeline.py -f script.txt --voice zh-CN-XiaoxiaoNeural --rate -25%
  → 段间停顿加长（bedtime场景600ms）
  → 加轻音乐BGM

Step 5: 交付
  → 返回 MP3（带章节标记）+ Markdown 文稿
  → 结尾温柔安抚语

### 场景C：推荐书籍（无指定书名）

用户："我想听关于投资的书，跑步时听"

Step 1: 解析参数
  → topic="投资", scene=running, age_group=adult

Step 2: 推荐书籍
  → 用 LLM 按 adult 的推荐类别生成3本推荐
  → 每本附简介+打动人的片段
  → 让用户选择

Step 3-5: 用户选择后，走正常流程
