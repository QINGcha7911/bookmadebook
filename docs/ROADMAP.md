# 🗺️ Roadmap

> 本项目由一人维护（AI Agent 团队协助），功能按优先级分批开发。
> 收集到的需求会分类标记，同类需求凑齐后统一开发。

## ✅ 已完成 (v1.0)

- [x] 核心流程：说书名 → 精读脚本 → TTS → 输出音频
- [x] 7级年龄段（0-3岁 ~ 18+），自动匹配声音/语速/时长
- [x] 6种场景预设（通勤/跑步/睡前/亲子/深度学习/午休）
- [x] 内容安全双模式（kids严格过滤 / adult宽松）
- [x] 流式交付：30秒出首段，后台续播
- [x] 智能推荐：话题 → 推荐书 + 高光片段
- [x] 笔记自动输出到 Obsidian

## 🔜 计划中 (v1.1)

- [ ] 书籍获取降级链：微信读书 → 安娜的档案 → Gutenberg → 用户上传
- [ ] L1/L2/L3 三级缓存（脚本/片段/成品），二次生成秒出
- [ ] 批量生成：一次选5本书，排队生成
- [ ] 试听功能：生成前先试听15秒风格
- [ ] 章节标记嵌入 MP3（支持跳转）

## 💭 讨论中 (v1.2+)

- [ ] 声音克隆（GPT-SoVITS 免费方案）— 让父母用自己的声音
- [ ] 亲子双版本：同一本书生成儿童版+家长版+讨论指南
- [ ] 播放列表 / 主题系列（"本周听一个关于XX的系列"）
- [ ] 多设备进度同步
- [ ] 定时生成（每天早上自动出今日通勤音频）
- [ ] 英文内容支持增强

## ❌ 暂不考虑

- 自有App/客户端（复用 Hermes/微信/飞书等现有入口）
- 视频生成（专注音频领域）
- 付费功能（保持完全免费开源）

---

## 需求处理说明

- 🟢 **简单需求**：直接回复，一般当天处理
- 🟡 **中等需求**：评估后加入 Roadmap，攒批开发
- 🔴 **复杂需求**：需要详细讨论，欢迎参与设计
- ⚪ **暂不考虑**：会礼貌说明理由，欢迎再议

> 由于是单人维护，回复速度取决于需求复杂度，感谢理解 🙏
