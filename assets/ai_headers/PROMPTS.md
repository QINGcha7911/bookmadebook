## 复用经验（写给下次生成的人）

1. **先问书的核心画面是什么**，不要直接写"日本/中国+风景"。
   问法：「这本书里最典型的**生活场景**是哪个？」→ 把它物化成物件。
2. **禁真人时的替代手法**：
   - 两副碗筷 / 两把椅子 / 两杯饮料 = 两个人
   - 一双拖鞋 / 晾着的衣服 / 桌上的眼镜 = 有人刚在
   - 灯亮着 / 门开着 / 半杯茶 = 有人存在
3. **冷暖对比**最能出情绪：室内暖光 + 室外冷色（月/雪/雨）。
4. **黄昏 ≠ 月**。书名带"月"就用**夜**，别用落日暖光。
5. 一条 ¥3.5，**先想清楚再生成**；不确定方向时先问用户（选择题比猜快）。

- 机器门禁：`person_part` 8 帧 0 命中 ✅
- 旁白：`川上弘美。老师的提包。`（husky_tender，2.56s）

### 同日新增的工程改动（写给下次生成的人）

1. **旁白必须做响度归一**：TTS 直出 mean ≈ −25dB，而正文是 loudnorm −16LUFS
   → 开场报书名**比正文轻 8dB**（实测）。已在 `ai_header.py::tts_vo` 内置
   `loudnorm=I=-16:TP=-1.5:LRA=11` → 复测片头 −17.0 vs 正文 −17.1（**差 0.1dB**）✅
2. **`--reuse --splice` 必须传 `--vo-file`**，否则 splice 走「静音片头 + 正文音轨延迟」老路径
   → **片头 5s 完全无声**（报书名的人声没了）。旁白 wav 按惯例存 `assets/ai_headers/<书名>_vo.wav`。
3. `qc_visual_scan.py` 已支持直接传单个视频文件（原先会把 5s 片头当成"清单文件"解析 →
   静默 0 段检查 = 假通过），并新增零素材直接报错退出。
