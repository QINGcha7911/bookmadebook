- prompt：`日本郊外住宅区的黄昏街景，安静的低矮民居与屋檐，远处电线杆的剪影，浅蓝色暮空升起一轮明月，路边自动贩卖机透出暖光，电线纵横，生活气息浓厚，写实纪录片风格，缓慢平移镜头，画面中没有任何人物`

  - 月亮做氛围而非主角（配合用户选的"中年日常"方向）

## 复用经验（写给下次生成的人）

1. **先问书的核心画面是什么**，不要直接写"日本/中国+风景"。
   问法：「这本书里最典型的**生活场景**是哪个？」→ 把它物化成物件。
2. **禁真人时的替代手法**：
   - 两副碗筷 / 两把椅子 / 两杯饮料 = 两个人
   - 一双拖鞋 / 晾着的衣服 / 桌上的眼镜 = 有人刚在
   - 灯亮着 / 门开着 / 半杯茶 = 有人存在
3. **冷暖对比**最能出情绪：室内暖光 + 室外冷色（月/雪/雨）。
4. **黄昏 ≠ 月**。书名带"月"就用**夜**，别用落日暖光。
5. 一条 ¥3.5，**先想清楚再生成**；不确定方向时先问用户（选择题比猜快）。
