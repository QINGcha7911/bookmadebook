## 用法（写进 cron 硬要求）
1. 合成前：把甲档命中的素材**无条件**加进该书排除清单。
2. 合成前：乙档命中的素材**必须**跑每段 6 帧 person_part VL，命中即排除。
3. 成片级终审仍要做（YOLO 逐秒 + 逐条 VL 放大裁决）—— 本清单只防"已知的坑"，不替代终审。

### 庚档 · 2026-09-15 素材量不足的处置边界（《秋园》实测，写给下一轮调度）
- 《秋园》清理后**净可用 76 段 / 84 个映射位**，而全片按 7s/镜需 **87 镜** → **复用不可避免**。
  最大流求解证明：即使把镜长放宽到 8.8s（68 镜）、把全部 76 段都用上，也**不存在零复用方案**
  （Ch5/Ch6 共享同一个 8 段的 `chinese_mountains_mist_dawn`，结构性冲突）。
- 因此把力气花在**「复用间隔最大化」**而不是「零复用」：全局 LRU 调度 + 冷却窗，
  实测把最短复用间隔从 **20.4s 提到 157.8s**（<120s 的复用 0 处）。
- **调度口径**（脚本 `/tmp/qy/compose_book_v9.py` 包装器，不改 `scripts/`）：
  ① 逐章建池口径与 `compose_scene_map` 完全一致；② 每章镜数 = `round(章时长/SHOT_LEN)` 且**不超过本章池容量**
  （池不够就拉长单镜，绝不章内循环）；③ 全片时间顺序调度，候选打分 =
  （是否在冷却窗内用过, 是否与上一镜同目录, -距上次使用的时间, -运动量）。
- **运动量阈值**：本片为消除复用周期，把 `MIN_MOTION` 2.0 → **1.2**，新增 7 段柔和运动素材
  （山雾 / 烛火 / 油灯 / 水面），已逐段目视 + VL 复核无真人/无现代元素；
  另用 `--allow-static` 放行 `crescent_moon_night_sky/04`（moon 过橙云，干净）。

### 壬档 · 2026-09-16 新增铁律：**航拍/屋顶俯瞰 = 小目标盲区**

   （全幅 → 下半幅 → 3x），**任一尺度报「有人/有车」即排除**；不许只跑一遍全幅。
2. **地域轴问句必须点名旗帜**：不要问「是不是本国场景」，要问

   VL 会把土耳其港湾判成「地中海，中性」，这正是本次漏检的机制。
3. **fail-closed**：YOLO 命中即使 VL 复看说「无人」，只要有**时序证据**
   （连续多帧、同一位置、同一形状在移动），一律按「有人」处置。
   夜景暗场 VL 可靠性低，**不得凭它的「无人」放行**。
4. 素材级 VL 普查采样点 = **片头偏置（0.05/0.3/0.8/1.6s）+ 中段（35%/50%/65%/85%）**；
