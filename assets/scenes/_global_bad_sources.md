## 辛档 · 验收口径【「相邻不重复 0 处」≠「全片零同源复用」】（007 于 2026-09-17 提出，采纳）

**坑**：`compose_book --dry-run` 报的「③ 相邻不重复 0 处」**只比对前后两镜**，
全片可能仍有 N 处同源复用（同一素材在不同章节/时段复现）而不被这一行拦下。
《目送》dry1 就是这么漏的：`全片净池 83 段` + `共 88 镜 | 素材去重 83/88` → **5 处复用**，
而「相邻不重复」那行照样是 0 处。
（该条早在《长日将尽》v3 被打回过，v7 的解法是放宽单镜时长让「镜数 ≤ 净池」。）

**判据（必须同时看两个数，缺一不可）**：
1. `共 N 镜 | 素材去重 N/N`（**相等**才算零复用）；
2. **N ≤ 净池唯一段数**。

**做法**：池不够就**放宽单镜目标时长**（`环境变量 QY_SHOT_LEN`，如 7.0→7.5s；观感无差别），
把镜数压到 ≤ 净池，而不是靠重复凑满时间轴。**宁可让单镜长一点，也不许同源复用。**

**近期实测**：《目送》终版 `净池 77 段 / 22 目录 → 共 76 镜 / 素材去重 76/76` ✅（76≤77，平均 8.9s/镜）；
《温柔的夜》v5 `净池 98 段 → 88 镜 / 88 唯一段` ✅。

**注意**：净池会因**排除清单变化**而缩小（《目送》06:31 时 83 段 → 终版 77 段，因两处真人各整目录排 3 段）。
所以放宽镜长后要**再跑一次 dry-run 确认镜数 ≤ 新净池**，不能沿用旧数字。
