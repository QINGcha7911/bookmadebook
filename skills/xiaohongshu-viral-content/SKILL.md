# 小红书爆款内容运营（2026 算法版）

> 类级技能：任何"小红书内容怎么发才能有流量/成爆款"的问题走这里。
> 背景：用户运营 AI 精读视频账号（bookmadebook 产物），10 分钟视频浏览量仅 ~100。

## 一、⚠️ 2026-09-19 实测更正：10 分钟视频**不是**死刑，瓶颈在封面

**先说被推翻的旧结论**（原写着「10min 大概率死在初始池」）：2026-09-19 用户提供小红书后台**《莫斯科绅士》**（片长 653.5s / 含片头 658.9s）的**笔记诊断**实测值 ——

| 轴 | 实测 | 后台评级 |
|---|---|---|
| 开头吸引力 | 5 秒完播率 **68.7%** | 较好 |
| 内容深度 | 平均观看 **351.5 秒**（÷653.5s = **53.8%** 完成度） | 较好 |
| 互动表现 | 互动率 **19.3%**（10.9min 长视频、且视频本身**零互动设计**） | 较好 |
| 视频画质 | 3.5 | 较好 |
| **流量转化** | **封面点击率 5.6%**（同类中位 **8.6%**，仅超 30% 同类） | **待提升** |

**结论：10 分钟载体 + 不设计互动，实测跑出 53.8% 平均观看 + 19.3% 互动 —— 内容侧四项全部优于/持平同类。唯一短板是封面点击率，5.6%/8.6% ⇒ 封面每拉平到中位数，同等曝光的进入量约 +54%。**
→ 因此：**不要再拿"10min 完播率死刑"解释低流量**（那会让团队去动产线，而产线不是瓶颈）；诊断一律先看**封面点击率**，再看标题搜索词。旧理论仅作历史留档（见下）。

### 附：旧结论留档（已被实测推翻，勿引用）

### 封面规格（2026-09-19 007 建议 · 待用户确认后进生产班）

实测《莫斯科绅士》的封面 = **片头截帧复用**：古典建筑穹顶仰视、**无人无情绪主体**，文字「莫斯科绅士」四字仅占画面高约 **1.5%**（手机缩略图里几乎不可见），点击率 5.6% vs 同类中位 8.6%。
**根因：封面不是"设计"出来的，是从片头里"捡"来的。**

改造规格（**不动产线结构，只在 `--reuse` 阶段多产一张 `封面.jpg`**）：

| 项 | 规格 |
|---|---|
| 尺寸 | **1080×1440（3:4 安全区）** 兼容 9:16 —— 信息流按 3:4 裁切，**关键文字必须落在中间** |
| 文字 | **一句钩子 ≤14 字**，字号 **≥画面高 8%**（约现值的 5 倍）；书名放左上小字（吃搜索+品牌） |
| 画面 | **单一视觉焦点 + 情绪主体**（背影/手/物件/建筑局部/光影；禁真人正脸照旧 ✓）；暖色/胶片感优于冷黑 |
| 合规 | 右下「AI 生成内容」角标**保留** ✓ |
| ⚠️ 反例 | 别把**视频内金句字卡**直接当封面 —— 字卡适合"看的时候"，封面是"决定要不要点的时候"，必须更重、更只留一句 |

**验证方式**：连续 3 篇换新封面（不做同内容重复发，避免判重），一周后看点击率 **5.6% → ≥8%**。

**标题配套（同一处根因）**：主推标题必须**书名 + 作者同框、且落在前 12 字**。实例教训：《莫斯科绅士》三个备选里只有 #3「读完《莫斯科绅士》…」含书名，而文案里写着「**推荐主用 #2**」= 无书名无作者那个 → 搜索占比仅 **0.7%**。**派单时直接指名主推标题，别让 004 自选"钩子最强"的那个**（钩子强 ≠ 搜得到）。

> 🚫 **用户决策红线（2026-08-23 定 + 2026-09-06 复确认）**：用户明确**不做产线改造**——不把每日 10min 精读改成双版本、不剪 60s 引流版、不投薯条。09-06 007 提供三选项（双版本每日必产/轻量试点/只配规范）用户全未选，原话「我希望提升小红书文案的水平」→ 用户认可的发力点 = **在现有 10min+文案产线上提升文案质量**（见 §九 四维诊断 + §八 模板），不是换载体。**此技能用于诊断/给建议时引用 60s 理论可以，但切勿主动推动 60s 钩子版生产落地**；用户问「怎么成爆款」时给一次参考即止，不反复推销（2026-08-23 已定）。

## 二、60 秒钩子版结构

```
0-3s    冲突钩子（悬念/反常识/痛点）—— 前 3 秒定生死
3-40s   核心亮点（2-3 个爆点，每 5 秒一个新信息点）
40-55s  金句字卡 + 情绪升华
55-60s  引导："完整版在主页/评论区"（引导听完整版的人自然去主页，涨粉率最高）
```

- 完整版 → 主页置顶或评论区引导
- 字数：~230 字正文 ≈ 60-66s（温柔慢语速 + 7s AI 声明）；295 字会冲到 1.4 分钟被 harness 拦截（偏差 >15% exit 3）——超了就删字重跑
- 执行链：quality_gate.py --target-minutes 1 → streaming_pipeline.py（--style ted）→ video_composer.py --fast

## 三、2026 算法机制（为什么这么设计）

**CES 公式**：`CES = 点赞×1 + 收藏×1 + 评论×4 + 转发×4 + 关注×8`
- 评论/转发/关注权重是点赞的 4-8 倍 → 内容要设计"让人说话"，不是"让人看完"
- 互动质量：>15 字长评论 > 短评；截图保存=极高价值信号；二次访问=长期价值

**流量池门槛**：

| 流量池 | CES 分 | 预估曝光 | 停留要求 |
|--------|--------|----------|----------|
| 初始池 | 0-50 | 200-500 | >3s |
| 初级池 | 50-200 | 2,000-5,000 | >5s |
| 中级池 | 200-800 | 10,000-50,000 | >8s |
| 高级池 | 800-3000 | 50,000-200,000 | >15s |
| 爆款池 | >3000 | 500,000+ | >20s |

- 完播率加权：每提升 10% 完播率，CES 额外 +15%
- 有效完播 > 强制完播：关键节点反复观看比全程快进价值高
- 目标基准：收藏率 ≥5%、评论率 ≥2%

**双引擎**：推荐流 ~60% + 搜索流 ~30-65%（搜索转化率是推荐流 3.2 倍，好内容可被搜 90 天）

## 四、标题 SEO（前 12 字含搜索词）

用户搜的是痛点/场景词，不是书名：
- ❌ 《山茶文具店》10分钟精读
- ✅ 「焦虑的人必看！这本治愈神作豆瓣9.0」
- ✅ 「不想上班就看这本书｜写给疲惫成年人的5句话」

## 五、互动 & 收藏设计

> 🚫 **用户红线（2026-09-12 定，优先级高于本节全部内容）**：用户明确否决**一切**「让人去评论区说话」的设计——投票句、二选一、连载/追更钩子、评论区引导、「扣1」、emoji 点缀，**均不得主动加进文案**。原话：「我觉得没必要用这种方式让大家在评论区评论，我只希望把不错的内容呈现给用户即可」。**本节以下内容降级为「诊断参考」**：只在用户主动问「怎么涨流量/怎么成爆款」时引用一次，**永不主动推动落地**。文案方向 = 把内容写真诚写扎实，评不评论、转不转发是读者自己的事。（2026-09-12 当日已派 004 产出互动试点版文案，踩线后整版废弃；评估误区的根因见 `evaluating-recommendations` §5.8 与 `references/ai-companion-market-2026-09.md`）

- 视频内主动提问："你有多久没手写过信了？评论区聊聊"
- 点单闭环（bookmadebook 已内置）："想听什么书，评论区报书名，下一本就做你的点单款"
- 发布后 1 小时内：置顶评论 1 条 + 回复所有评论（互动速度 > 总量）
- 收藏率设计：内容做成清单式（"这本书的5个治愈瞬间""3句值得抄下来的话"），封面文字直接写金句截图即收藏

## 七、⚠️ AI 味风险（2026 平台识别增强）

- "冷冰冰的 AI 内容很难拿高流量"，平台有人工修正机制

## 十一、封面规范（2026-09-19 新增 · 由《莫斯科绅士》5.6% 实测倒推）

**背景**：该篇封面点击率 5.6%（同类中位 8.6%，仅超 30% 同类），是全篇唯一短板；其余四轴（5秒完播 68.7% / 平均观看 53.8% / 互动 19.3% / 画质 3.5）全部达标。
**根因**：生产班原第七步写的是「⑦ **封面抽帧**」—— 直接从成片抽一帧当封面，结果封面无人、无钩子、书名仅占画面高 **1.5%**，手机缩略图里看不见。

### 硬规范（脚本自动保证）
| 项 | 要求 |
|---|---|
| 尺寸 | **1080×1440（3:4 信息流安全区）**，同时出 1080×1920（9:16）兼容版 |
| 文字 | 一句钩子 **≤14 字**，字号 **≥ 画面高 8%**（1440 下 ≥115px） |
| 构图 | 单一视觉焦点；底部渐变压暗保可读 |
| 信息 | 左下 **《书名》+ 作者名**（吃搜索/品牌）；右下 **「AI 生成内容」角标**（合规） |
| 底图 | 必须来自**已过门禁的可用清单**、年代贴合（酒店/器物/室内）；**禁现代街景、禁真人** |
| 断行 | 优先在标点断，两行尽量等长，**末行不出现孤立单字** |

### 生成器：`scripts/make_cover.py`（bookmadebook 仓库）
```bash
python3 scripts/make_cover.py --book 莫斯科绅士 --author 埃默·托尔斯 \
  --hook "被软禁32年，最优雅的活法" \
  --base assets/scenes/book_莫斯科绅士/grand_hotel_lobby_marble \
  --out <归档>/莫斯科绅士_封面.jpg --also-916
```
自带四个防坑设计（都是实测踩出来的）：
1. **自动跳过 `book_<书名>_excluded.json` 里的素材** —— 不跳会抽到真人素材（实测 `library_ladder_books` 被抽出一张有女人的帧，而该目录 6 个文件里 4 个已被排除）
2. **在多帧里挑"信息量最大"的一帧**（边缘方差评分，过亮/过暗重罚）—— 固定抽 40% 会抽到空雾帧
3. 断行优先标点、两行等长（避免「…最」/「优雅的活法」这种把「最」孤零零留在行尾）
4. `--base` 可传**目录**（自动在目录内挑帧）或具体文件

### 派单时怎么定钩子
取**讲书稿开场第一句**（004 写的开场钩子本就是冲突/画面/反常识句）压到 ≤14 字。例：《莫斯科绅士》→「被软禁32年，最优雅的活法」。
