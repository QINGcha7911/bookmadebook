# 商品清单：结构、合规、实测价核对（2026-09-18 实操）

小红书交付包四件之一（**文案 / 清单 / BGM / 视频地址**，齐发短视频群，漏发用户必追问）。
清单由 005 侧生成（**它没有 web_search**）→ **实测价核对 + 禁互动清理是 007 的活**。

## 一、结构

```
# 《书名》商品清单
| # | 商品 | 参考价（实测核对） | 与书内容的对应 |
【用法建议（价值等式嵌入，勿硬挂）】   ← 2-3 条口语化推荐，把物和文化内容勾住
【合规】                               ← 图书/食品/工艺品实物；无理财无医疗断言；食品标保质期
【内部备注（不进落地页）】             ← 本片 md5 / 口径 / 修订说明
```

- 模板要求「**≤100 元 5 件**，内容化话术」；实际产出常 6-7 件（含食品/工艺品），用户未异议 → 以「与书内容强对应」为准，不要为凑数硬挂。
- **禁互动适用于清单**（见 SKILL.md §五/§十）：那种「文末互动：评论区扣 1，我把书里原句整理成清单发你」的句子**必须删**——它既是索取式 CTA，也正被用户 09-12 红线否决。
- 清单里可以有点单/橱窗式推荐（「橱窗里那本 20 多块的人民文学版最省事」），但**不索取、不承诺**。

## 二、实测价核对方法（2026-09-18 定）

用 `execute_code` 把 N 个搜索批量跑完（7 项 ≈ 18s），**逐项打印抓到的价位 + 例源**，再人工判断可信度。

**能用的来源**（snippet 里直接带价，可直接引用）：
| 类型 | 来源特征 | 例子（09-18 呼兰河传） |
|---|---|---|
| 食品/工艺品 | 淘宝 Top-N 列表页 snippet：`￥\d+` + 「已售 N 件」 | 冻梨 5 斤包邮 ¥15.8；粘豆包 5 斤 ¥24.9 / 手工包邮 ¥67 |
| 食品/工艺品 | 什么值得买、京东：到手价 + 折后单价 | 冻梨 5 斤 京东 ¥29.9 → 折后 29.6（5.9/斤） |
| 图书（套装） | 豆瓣条目价 | 「萧红全集」五册 = ¥160 |
| 产地直发 | 一亩田等：`\d+ 元/斤` | 冻梨通货 6.00 元/斤（4 斤起） |
| 单只小物 | 淘宝列表页最低价 | 莲花河灯单只 ¥4.28 起 |

**噪声来源（别信）**：
- 泛词查询（「呼兰河传 价格」「呼兰河传 京东」）→ snippet 里混进 **349 / 1964 / 501 / 1139** 这类完全无关的数字（评价数、销量、折数）。
- 正则抓 `[¥￥]\d+|\d+元` 会把**评价数、销量、「5.4 折」**一起抓进来 → 必须回看 snippet 原文，不能只看抓出来的数组。
- 抓不到就**别编**：书写「约 ¥20–45（各平台常见区间；未取到单一定价）」是可以的；把噪声数字当「实测价」写进去不行。

**标注纪律**：区间价标「约 ¥X–Y」+ 一句来源/口径；同品类跨店铺价差大的（粘豆包 ¥24.9~67）写清规格与档位。**价格与库存以落地页实时为准**这句合规话必须留——清单会被用户直接抄进落地页。

## 三、收尾

1. 改完写回原文件（同目录 `.bak_<主题>_<时间戳>` 备份）。
2. 文件若被 `read_file` 判为 binary（编码怪癖），用 `python3 -c "print(open(p,'rb').read().decode('utf-8',errors='replace'))"` 读全文再改。
3. 发群时**独立成条**（别并进交付长报告）——用户要直接复制。
4. 若当轮价格确实核不动，就**如实标「区间估计（未实测）」并说明**，不要静默降级。
